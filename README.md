# Mapiya

**MAPIYA contact map server for identification and visualization of molecular interactions in proteins and biological complexes**

Mapiya is a web server that integrates generation of contact maps (intramolecular and intermolecular) for proteins, nucleic acids, and their complexes; characterization of the interactions' physicochemical nature; and interactive visualization of biomolecular conformations.

**Webserver:** [https://mapiya.lcbio.pl/](https://mapiya.lcbio.pl/)
